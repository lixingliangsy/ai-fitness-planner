# AI Fitness Planner — Feature pillars

## Core engine
- Personalized workout blocks with adjustable difficulty.
- Optional high-level diet suggestions (not medical nutrition therapy).
- Equipment-aware exercise selection.

## Workflow ownership
- 3-step pipeline: profile → blocks → adjustable plan.
- Deterministic fitness-plan rules with rulesetVersion.
- Distinct from Plan Generator (blocks+diet vs schedule export).

## Trust & honesty
- Decision-support only — not a medical device or prescription.
